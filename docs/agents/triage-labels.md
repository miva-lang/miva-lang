# Triage Labels

| Label | Meaning |
|-------|---------|
| `needs-triage` | Not yet reviewed or categorized |
| `needs-info` | Missing information, waiting on user |
| `ready-for-agent` | Reviewed and ready for implementation |
| `ready-for-human` | Needs human review (e.g., design approval) |
| `wontfix` | Intentionally not fixing |
