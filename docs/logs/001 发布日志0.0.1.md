# MVP v0.0.1 "Genesis"

> **First Breath.**
> MVP 语言的第一个可用版本。显式、安全、可预测。

---
## 🎉 版本概要

这是 MVP 语言的**首个可用里程碑**。

- ✅ **编译管道**：已支持**编译到 C++** 后端。
- ✅ **核心安全**：基础**所有权模型**已实现并在编译期强制检查。

---

## 🚀 功能详情

### 1. 变量声明

MVP 采用统一的声明语法，默认不可变，并遵循 RAII 语义。
**语法示例：**

```mvp
x := 42          // 不可变绑定（自动推导类型）
mut y := [1, 2]  // 可变绑定
```

**规则：**

- **唯一操作符**：仅使用 `:=` 进行声明。
- **默认不可变**：需要修改时必须显式添加 `mut` 关键字。
- **自动析构**：作用域结束时自动调用析构函数（RAII）。

---

### 2. 所有权操作

显式的内存管理，拒绝隐式拷贝。

| 操作        | 语法        | 语义                      |
| --------- | --------- | ----------------------- |
| **所有权转移** | `move x`  | 放弃 `x` 的所有权，`x` 立即失效    |
| **深拷贝**   | `clone x` | 创建 `x` 的语义正确副本，`x` 保持有效 |

**代码示例：**

```mvp
a := [1, 2, 3]
b := move a    // a 所有权转移给 b，a 此后不可用
c := clone b   // b 仍可用，c 是独立的深拷贝副本
```

**赋值规则：**

- **Copy 类型**（如 `int`, `bool`, 纯值 `struct`）：
  - ✅ 允许隐式复制：`y := x`
- **Non-Copy 类型**（如 `[T]`, `string`）：
  - ❌ 禁止隐式复制：`y := x` (Compile Error)
  - ✅ 必须显式操作：`y := move x` 或 `y := clone x`

---

### 3. Copy 类型判定

编译器在 AST 阶段静态分析类型是否为 Copy，用户无法干预。
**判定规则：**

- **是 Copy**：
  - 内置简单类型：`int`, `bool`, `float32`, `float64`, `char`
  - 所有字段递归为 Copy 的 `struct`
- **非 Copy**：
  - 动态数组 `[T]`
  - 字符串 `string`
  - 含系统资源的结构体（如文件句柄）

---

### 4. 函数定义
		 
**语法示例：**

```mvp
add = (a: int, b: int): int => a + b
greet = (ref name: string): void => {
    // 多语句函数体
    print("Hello, ", name)
}
```

**规则：**

- **一等值**：函数可赋值、传递、返回。
- **单表达式函数**：省略 `{}` 与 `return`。
- **多语句函数**：最后表达式自动返回；提前退出用 `return expr`。
- **返回值类型**：暂不支持自动推导，需在参数列表后使用 `: type` 显式注明。

---

### 5. 参数传递

函数参数传递语义明确，杜绝歧义。

| 语法         | 语义    | 调用方式          |
| :--------- | :---- | :------------ |
| `ref x: T` | 只读借用  | `f(arg)`      |
| `x: T`     | 所有权接管 | `f(move arg)` |

**代码示例：**

```mvp
// 借用：标 ref
hash = (ref data: [byte]): int => { ... }
// 所有权：不标（默认）
save = (f: File): void => { ... }
main = (): int => {
    buf := [1, 2]
    file := open_file()
    h := hash(buf)        // ✅ 借用，buf 仍有效
    save(move file)       // ✅ 转移，file 失效
}
```

**限制：**

- ❌ 禁止未标注的 non-Copy 参数隐式复制（如 `(x: [int])` 会报错）。
- ❌ v0.0.1 不支持可变借用 (`mut ref`)。

---

### 6. 内置类型 (v0.0.1)

| 类型      | 说明                                            |
| :-------- | :---------------------------------------------- |
| `int`     | 64 位有符号整数（平台无关）                     |
| `bool`    | `true` / `false`                                |
| `float32` | 32 位 IEEE 754 浮点                             |
| `float64` | 64 位 IEEE 754 浮点                             |
| `char`    | Unicode 标量值 (U+0000–U+D7FF, U+E000–U+10FFFF) |
| `[T]`     | 动态数组（堆分配，Non-Copy）                    |
| `string`  | UTF-8 编码字符串（Non-Copy）                    |
| `struct`  | 用户自定义结构体                                |

---

### 7. 控制流 (v0.0.1)

基础控制结构支持：

- `if condition { ... } else { ... }`
- `return expr` （用于提前退出）
  > 所有控制结构均为表达式（将在未来版本扩展）。

---

### 8. 内存安全保证

MVP 在编译期提供以下安全保障：

- ✅ 无裸指针，无手动内存管理。
- ✅ 编译期跟踪变量状态：`valid` / `moved`。
- ✅ 禁止使用已 `moved` 变量（编译错误）。
- ✅ 借用期间禁止 `move`（编译错误）。
- ✅ Non-Copy 类型禁止隐式复制。

---

### 9. 词法约定：语句终结

MVP 源码**不使用分号**作为语句终结符。
**自动终结规则：**

- 语句在换行处自动终结，前提是当前语法结构已完整。
- 编译器依据上下文判断是否延续下一行（类似 Go 语言的 ASI 规则）：
  - **续行**：行末为操作符（如 `+`, `=`, `=>`, `(`, `[`, `{`, `,`）。
  - **终结**：下一行起始为独立语句（如 `if`, `for`, `IDENT :=`, `}`）。
    **错误处理：**
- 分号在词法分析阶段视为非法 token，出现时报告 `syntax error`。
  > 此设计确保语法简洁、无歧义，且与表达式导向风格天然契合。
