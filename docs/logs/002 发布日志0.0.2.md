## 📦 详细说明

### 1. 工具链统一

```bash
mvp init <project>     # 初始化项目，生成 mvp.toml
mvp build              # 编译项目
mvp run                # 编译并运行
mvp clean              # 清理构建缓存
```

- 使用 `cmdliner` 作为命令行解析库
- 支持 `mvp.toml` 项目配置与依赖管理
- 自动解析依赖并构建

**mvp.toml 示例：**

```toml
[project]
name = "myproject"
type = "bin"
```

---

### 2. `choose` 匹配语句

```mvp
choose (x) {
  when (case1) {
    // ...
  }
  when (case2) {
    // ...
  }
  otherwise {
    // ...
  }
}
```

|特性|说明|
|---|---|
|语法|`choose (表达式)` + `when (条件)`|
|编译行为|展开为 C-style `if-else`|
|守卫 (guard)|❌ 暂不支持（如 `when (x > 0)`）|
|表达式模式|❌ 暂不支持作为表达式|

> ⚠️ **注意**：`choose` 和 `when` 后的表达式**必须加括号**

---

### 3. `if` 内 `move` 分析（悲观合并）

若 **任一分支** 对变量执行 `move`，则 `if` 结束后该变量**全局视为 `moved`**：

```mvp
if cond {
  move buf  // buf moved in true branch
} else {
  // nothing
}
// ❌ 编译错误：buf may be moved
```

> **设计哲学**：v0.0.2 以安全为先，路径敏感分析将在后续版本引入。

---

### 4. 基础模块化（文件即模块）

#### 设计原则

- 每个 `.mvp` 文件 = 一个独立模块
- 模块内符号**默认私有**，需显式 `export`

#### 导出

```mvp
module "example.foo"  // 文件开头必须声明模块名

foo = (): int => 2  // 私有
export foo          // 公开
```

#### 导入

```mvp
import "std/math"        // 引入 std/math.mvp
result := std.math.sqrt(4)

import "utils/io" as io  // 指定别名
io.println("Hello")
```

#### 已知限制

- ❌ 循环依赖检测将在 v0.0.3 添加
- ⚠️ 用户需自行避免循环导入

---

### 5. 结构体初始化语法变更 ⚠️

```mvp
// ❌ v0.0.1 风格（不再支持）
Point { x: 1, y: 2 }

// ✅ v0.0.2 风格（需要 struct 关键字）
struct Point { x: 1, y: 2 }

// ✅ 跨模块结构体
struct helper.Point { x: 1, y: 2 }
```

|变更|说明|
|---|---|
|旧语法|`StructName { ... }`|
|新语法|`struct StructName { ... }`|
|原因|避免与字段访问歧义（`a.b.c` 是模块路径还是字段？）|
|影响|⚠️ Breaking Change，v0.0.1 代码需迁移|

---

### 6. 自动 `return`

- **单表达式函数** → 自动返回
- **多语句块** → 最后一条表达式自动作为返回值

```mvp
add = (a: int, b: int): int => a + b  // 单表达式

greet = (name: string): string => {
  msg := "Hello, " + name + "!"
  msg  // 自动 return
}
```

---

### 7. `main` 函数简化

用户只需写：

```mvp
main = () => {
  println("Run!")
}
```

编译器自动：

1. 将用户 `main` 重命名为 `mvp_main`
2. 生成 C 入口点：
    
    ```c
    int main() {
        mvp_main();
        return 0;
    }
    ```
    

> ✅ 用户不再写 `: int` 或 `return 0`，专注逻辑本身

---

### 8. 基础内置函数

```mvp
main = () => {
  println("Hello from MVP!")  // ✅ 内置，无需 import
  printlns("Formatted: ", 42) // ✅ 内置，无需 import
}
```

|特性|说明|
|---|---|
|实现方式|**header-only 库**（绑定 libc）|
|可见性|**自动可见**，无需 `import`|
|常见函数|`println`, `printf`, `malloc`, `exit` 等|
|扩展|用户可通过 `import` 引入更多标准库|

> ✅ 常用函数开箱即用，复杂功能按需导入
