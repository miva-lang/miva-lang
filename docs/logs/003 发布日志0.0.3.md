## ✨ 新增特性

### 1. 所有权静态检查 🔒

完整的编译期所有权检查，杜绝 use-after-free 和 double-free。

**检查范围**：

| 场景 | 行为 | 状态 |
| :--- | :--- | :--- |
| `move ref_x` | ❌ 报错：Cannot move a borrowed reference | 已实现 |
| `clone ref_x` | ✅ 通过，正常复制 | 已实现 |
| `choose` 分支内 move | ✅ 悲观合并检查 | 已实现 |
| 函数返回 ref | ❌ 报错：Cannot return borrowed reference | 已实现 |

**编译流程**：
```
源码 → 词法分析 → 语法分析 → 语义分析 → [所有权检查] → 代码生成
                                              ↑
                                          v0.0.3 新增
```

---

### 2. FFI 框架 🌉

支持与 C 语言无缝互操作。

**语法**：
```miva
import "c:stdio.h"        // 转换为 #include <stdio.h>
import "c:stdlib.h"       // 转换为 #include <stdlib.h>
import "c:mylib/mylib.h"  // 转换为 #include "mylib/mylib.h"
```

**实现细节**：

| 问题 | 解决方案 |
| :--- | :--- |
| 头文件搜索路径 | 添加 `-I` 参数，支持 `$MIVA_INCLUDE` 环境变量 |
| 命名空间 | `c.xxx` → `xxx`（去前缀） |
| 名称冲突 | 检测 Miva 内置函数名，报错提示 |
| 安全性 | 只能在 `unsafe` 或 `trusted` 函数中调用 |

**示例**：
```miva
import "c:stdio.h"

unsafe main = () => {
    c.printf("Hello, %d\n", 42)
}
```

---

### 3. unsafe/trusted 安全模型 🛡️

三层安全模型，比 Rust 更精细的 unsafe 管理。

| 类型 | 定义 | 调用规则 |
| :--- | :--- | :--- |
| **safe** | 默认，无 unsafe 调用 | 可调用 safe/trusted |
| **unsafe** | 含 unsafe 操作 | 只能被 unsafe/trusted 调用 |
| **trusted** | 含 unsafe 但作者保证安全 | 可被任何函数调用 |

**示例**：
```miva
// unsafe 函数（必须显式声明）
unsafe foo = () => {
    c.printf("hello")
}

// trusted 函数（作者保证安全）
trusted bar = () => {
    foo()  // 内部封装，外部安全
}

// safe 函数（默认）
baz = () => {
    bar()  // 可以调用 trusted
}
```

### 5. 内联 C 代码 🔧

支持在 Miva 源码中直接内联 C/C++ 代码。

**语法**：
```miva
c unsafe foo = (inp1: int, inp2: int): int => """
    return inp1 + inp2;
"""
```

**检查规则**：

| 检查项    | 规则                |
| :----- | :---------------- |
| C 代码验证 | 不验证（用户自负风险）       |
| 安全性    | 自动标记为 `unsafe`    |
| 嵌套     | 不允许嵌套 `c unsafe`  |

**生成代码**：
```cpp
// 直接内联，零开销
auto foo = [](int inp1, int inp2) -> int {
    return inp1 + inp2;
};
```

---

### 6. 循环依赖检测 🔍

编译期检测模块循环依赖，避免编译错误。

**算法**：DFS 检测环

**错误示例**：
```miva
// a.miva
import "b"  // ❌ 循环依赖：a → b → a

// b.miva
import "a"
```

**错误输出**：
```
error: Circular dependency detected
  --> a.miva:1:1
   |
1  | import "b"
   | ^^^^^^^^^^
   |
   = note: a → b → a
```

---

### 7. 基础测试框架 🧪

内置测试支持，无需外部工具。

**语法**：
```miva
test io_print = () => {
    std.io.println("hello")
}

test assert_demo = () => {
    assert(1 + 1 == 2)
    assert_eq(add(2, 3), 5)
}
```

**命令**：

| 命令                    | 说明     |
| :-------------------- | :----- |
| `miva test`           | 运行所有测试 |

**实现细节**：

| 特性       | 实现方式                   |
| :------- | :--------------------- |
| 编译       | 测试函数编译为普通函数            |
| 输出       | 单独 `.cpp` 文件，含 main 入口 |
| 返回值      | `0` = 全部通过，`非 0` = 有失败 |
| panic 处理 | panic 返回非 0            |
