## ✨ 特性详情

### 1. 环境变量管理 🔧  
**项目级配置，优先于全局**

现在可通过 `miva.toml` 声明项目专属环境变量，覆盖系统默认值。

```toml
# miva.toml
[env]
MIVA_STD = "./std"           # 标准库路径
MIVA_INCLUDE = "./include"   # 头文件搜索路径
MIVA_DEBUG = "true"          # 调试模式开关
```

使用 `miva init` 初始化项目时，将自动生成合理默认值：
```toml
[env]
MIVA_STD = "."  # 指向项目根目录
```

**优先级规则**：  
`miva.toml` > 系统环境变量 > 编译器内置默认值

---

### 2. 库编译支持 📦  
**让 Miva 代码被其他语言调用**

新增 `--lib` 模式，支持生成跨平台动态库：

```bash
miva build              # 对lib项目，生成 .so / .dll / .dylib
miva build              # 对bin项目，生成可执行文件
# miva build --static  # 静态库（规划中）
```

配置示例：
```toml
[lib]
name = "mylib"
type = "lib"  # 可选: lib | static（后者待实现）
```

输出结构：
```
build/
├── mylib.so      # Linux
├── mylib.dll     # Windows
└── mylib.dylib   # macOS
```

---

### 3. 增量编译 ⚡  
**改一行，不重编百行**

基于源文件 SHA256 哈希的增量编译系统，大幅缩短迭代时间。

**工作流程**：
```
源文件 → 计算哈希 → 比对缓存 → 决定是否跳过编译
```


---

### 4. 赋值静态检查 🛡️  
**拒绝隐式复制，拥抱显式所有权**

对非 `Copy` 类型（如 `string`、`box<T>`），编译器将在 C++ 后端插入 `static_assert`，防止意外复制。

**Miva 源码**：
```miva
x := get_string()  // string 不可复制
y := x             // ❌ 编译错误！
```

**生成的 C++ 代码**：
```cpp
auto x = get_string();
static_assert(is_copyable_v<decltype(x)>,
    "Type 'string' is not copyable. Use 'move x' or 'clone x' explicitly.");
auto y = x;  // 此行触发断言失败
```

**Copy 规则**：
- ✅ 基础类型（`int`, `bool`, `f64`）：可复制
- ❌ 所有权类型（`string`, `[T]`, `box<T>`）：不可复制
- 📦 自定义 struct：仅当所有字段均可复制时，整体可复制

> ⚠️ **迁移注意**：旧代码中若存在隐式复制非 Copy 类型，需显式改为 `move x` 或 `clone x`。

---

### 5. 测试运行优化 🧪  
**精准运行，快速反馈**

支持按文件或测试名称过滤，告别“全量跑 2 分钟只为验证一个 case”。

```bash
miva test               # 运行全部测试
miva test io            # 仅运行 src/io.miva 中的测试
miva test --verbose     # 显示详细日志（含通过/失败用例）
```

---

### 6. 美观输出 🎨  
**清晰、友好、有重点**

- 编译成功/失败信息使用彩色标识（绿色 ✓ / 红色 ✗）
- 错误位置高亮显示
- 构建耗时自动统计并展示

> 🌈 未来支持 `NO_COLOR=1` 环境变量关闭彩色输出（CI 友好）
