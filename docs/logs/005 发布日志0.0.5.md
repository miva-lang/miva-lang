# 🎉 Miva v0.0.5 Released  
> **From pleasant to practical**

我们很高兴地宣布 **Miva 编程语言 v0.0.5** 正式发布！  
本版本聚焦于**夯实表达力、扩展标准能力、铺平工具链基础**，让 Miva 从“可玩”迈向“可用”。

---

## 🔧 核心更新

### 1. **`elif` 语法糖上线**
多分支逻辑从此更清晰：
```miva
if (x < 0) {
    log("negative")
} elif (x == 0) {
    log("zero")
} else {
    log("positive")
}
```
语义完全等价于 `else { if ... }`，零运行时开销，只为提升可读性。

---

### 2. **原生指针类型：`box<T>` 与 `ptr<T>`**
- `box<T>`：唯一拥有的堆指针，支持移动，不可复制 → 对应 C++ `std::unique_ptr<T>`
- `ptr<T>`：不安全裸指针，仅限 `unsafe` 块中解引用 → 对应 `T*`

这为 FFI、自定义容器、系统级编程打开大门，同时保持内存安全边界。

---

### 3. **模块导入支持别名：`import as`**
解决命名冲突从未如此简单：
```miva
import "std/json" as sjson
import "mylib/json" as tjson

sjson.parse(...) // 明确来源
```
也支持通配导入（谨慎使用）：
```miva
import "std/macro" as .  // 将宏直接引入当前作用域
```

---

### 4. **子目录构建支持**
项目结构更自由：
```bash
miva init myapp --type=bin
cd src/
miva build  # ✅ 现在合法！
```
编译器会自动向上查找 `miva.toml`，无需返回根目录操作。

---

### 5. **`--release` 构建模式**
性能敏感场景终于有专用路径：
```bash
miva build            # debug：含调试符号，无优化
miva build --release  # release：-O2 -DNDEBUG，剥离调试信息
```

---

### 6. **内置宏系统（v1）**
首批只读宏已就位，安全且卫生：
```miva
printlns!("hello", "world")        // 依次输出
assert!(x > 0)
let content = include_str!("data.txt")  // 编译期嵌入
```
- 不允许用户定义宏（留待 v0.1.0）
- 无变量捕获，无作用域污染
