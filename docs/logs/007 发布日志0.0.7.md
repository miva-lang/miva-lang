# 🦉 Miva v0.0.7 Released
> **Silent Owl**

我们很高兴地宣布 **Miva 编程语言 v0.0.7** 正式发布！
本版本聚焦**类型系统稳定、编译器指令、错误编码、工程化配置、语法规范化**，让 Miva 从**能跑**正式迈向**好用、严谨、可维护**。

---

## 🔧 核心更新

### 1. 类型推导全面修复
- 新增**内置函数类型注册表**，补齐所有内置函数的返回值与参数类型
- 修复 `for` 循环变量类型缺失问题，迭代变量自动加入环境 env
- 所有函数（无论 safe / unsafe）统一进入严格类型检查

### 2. 魔法注释（编译器指令）上线
新增 `/!` 指令，用于向编译器下达控制命令：
- `/!warning_off <code>` 关闭指定警告
- `/!warning_err <code>` 将警告升级为错误
- `/!release <mode>` 设置编译优化级别
- `/!mangle <on|off>` 控制符号修饰，专为 FFI 设计

### 3. 注解注释系统上线
新增 `@` 注解，用于文档、IDE、代码审查：
- `@impl` 说明结构体实现的行为
- `@unsafe` 说明不安全函数的风险
- `@trusted` 说明为什么 unsafe 调用是安全的

### 4. 错误 & 警告编码体系
- 错误：`E0001 ~ E0999`
- 警告：`W0001 ~ W0999`
所有信息可被工具链精确识别、开关、跳转。

### 5. 分号语法正式加入（必写）
Miva 从 0.0.7 开始**强制使用分号**，以消除解析歧义，提升编译器稳定性。

**必须加分号的位置：**
- 函数内部的所有语句（Stmt）
- 函数内部的所有表达式（Expr）
- 模块声明语句
- 模块导入语句
- 函数导出语句

### 6. 编译器配置文件
支持两级配置：
- 全局：`~/.miver/config/miva.toml`
- 项目：`./.miva.toml`

配置优先级：内置默认 < 全局 < 项目

---

## 🚫 破坏性更新

### 1. **强制分号（重大 breaking change）**
所有旧版本 Miva 代码**必须添加分号**才能在 0.0.7 中编译通过。

**需要添加分号的位置：**
- 模块声明
- 模块导入
- 函数导出
- 函数内部所有语句
- 函数内部所有表达式
