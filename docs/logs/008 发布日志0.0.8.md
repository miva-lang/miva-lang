## 🚀 核心更新

### 1. 编译期宏系统（Compile-time Macros）
引入强大的宏系统，支持编译期代码生成与语法抽象，**零运行时开销**。

**语法：**
```miva
macro debug_log = ($tag: string, $msg: string) => {
  print("[");
  print($tag);
  print("] ");
  print($msg);
  print("\n");
}

// 调用
debug_log!("INFO", "server started");
```

**特性：**
- 宏参数以 `$` 标识，支持任意表达式、语句、标识符
- 编译期展开，无运行时成本
- 宏作用域遵循模块可见性规则
- 宏体内可使用所有 Miva 语法与内置函数
- 展开后由类型检查器统一校验，保证类型安全

**约束：**
- 宏仅在编译期执行，不生成运行时函数
- 宏不支持递归调用（防止编译死循环）

---

### 2. 显式类型注解（Explicit Type Annotations）
在类型推导基础上，提供**可选的手动类型标注**，增强代码可读性与工程健壮性。

**语法：**
```miva
let x int = 42;
let flag bool = true;
let name string = "Miva";
let ptr ptr<int> = null;
```

**规则：**
- 类型注解为**可选语法**，不影响原有类型推导
- 手动注解后，编译器强制执行严格类型匹配，**不允许隐式转换**
- 类型检查器在编译期严格校验注解与赋值是否匹配

**示例：**
```miva
let x int = 1;      // ✅ 正确
let y string = "ok"; // ✅ 正确
let z int = "hello"; // ❌ 类型不匹配，编译报错
```

---

### 3. 自定义类型运算符注册（Operator Overloading）
支持结构体绑定自定义运算符实现，开启面向数据的优雅编程范式。

**语法：**
```miva
Vector = struct {
  x: int,
  y: int
};

add_vector = (a: Vector, b: Vector): Vector => {
  return Vector { x: a.x + b.x, y: a.y + b.y };
};

impl Vector {
  operator_add = add_vector;
}

// 使用
let v1 = Vector { x: 1, y: 2 };
let v2 = Vector { x: 3, y: 4 };
let v3 = v1 + v2;  // Vector { x: 4, y: 6 }
```

**支持的运算符：**
- `operator_add`  (+)
- `operator_sub`  (-)
- `operator_mul`  (*)
- `operator_div`  (/)

**查找规则：**
1. **其他模块的结构体**：优先使用结构体所属模块内的 `impl` 实现；若无，则使用当前模块的 `impl` 实现
2. **当前模块的结构体**：必须在当前模块内实现 `impl`，不允许跨模块为本地结构体注册运算符

### 4. 标准库：std.mem（底层内存操作）
新增 `std.mem` 模块，基于 C 标准库内存 API 提供底层内存操作能力，全部函数显式标记为 `unsafe`。

**API：**
```miva
use std.mem;

// 分配内存
let ptr = mem.alloc(1024);  // 分配 1024 字节

// 重新分配
let new_ptr = mem.realloc(ptr, 2048);

// 指针偏移
let offset_ptr = mem.offset(ptr, 128);

// 释放内存
mem.free(ptr);
```

**核心约束：**
- 全部函数声明为 `unsafe`，调用必须在 `unsafe`/`trusted` 作用域内
- 基于 C 标准库 `malloc`/`realloc`/`free` 封装
- 无自动内存管理，遵循 Miva 显式安全原则
- 指针转换严格受控，避免隐式风险
- `allocPtr` 专用指针类型，确保类型安全

### 5. 测试框架美化（Test Output Enhancement）
测试报告全面升级，提供更清晰、直观、专业的输出体验。

**新特性：**
- 🟢 **彩色终端输出**：通过为绿色，失败为红色，警告为黄色
- 📊 **详细失败报告**：失败用例名称、位置（文件+行号）、预期值与实际值对比、错误原因
- 📈 **结构化统计**：总用例数、通过数、失败数、跳过数、总耗时
- 🎯 **快速定位**：失败用例一目了然，便于问题排查

**使用方式：**
原有测试语法不变，编译器自动使用新格式输出测试结果。

  print(", ");

// 使用
