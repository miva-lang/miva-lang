# 🦉 Miva v0.0.9 Released
> **Soaring Eagle**

我们很高兴地宣布 **Miva 编程语言 v0.0.9** 正式发布！

本版本标志着 Miva 从"强大"迈向"完善"的关键一步，带来了**泛型操作**的核心能力，同时大幅优化了CLI美观程度。Miva 正在成为一门兼具表达力与系统级能力的现代编程语言。

---

## 🚀 核心更新

### 1. 泛型支持
引入完备的泛型，支持通过实例化实现的泛型操作。

**语法：**
```miva
foo[T, U] = (param: T):U => ...

export foo;

foo[int,string](1); // 显式
foo(1); // 隐式（需足够上下文）

bar[T] = struct {
  a: T, 
  b: int
}
```

**特性：**
- 泛型参数包裹在`[]`中，避免重载歧义
- 编译期实例化，无类型擦除成本
- 可以如普通函数和结构体般使用

---

### 2. 标准库增强（std.str）
在泛型的基础上，为std.str添加from函数，功能同string_from

**语法：**
```miva
n := std.str.from(1); // n为"1"
```

**示例：**
```miva
a := std.str.from(1);
b := std.str.from(true);
```

---

### 3. Miver更新
支持按标签的下载，避免仓库过大、下载缓慢

**使用：**
```bash
miver init -t v0.0.8 // 到v0.0.8
miver init -t v0.1.0 // 从v0.0.8起，包含v0.0.9
```

**重点：**
- 最新v0.0.9只在v0.1.0标签中出现，务必下载该标签
