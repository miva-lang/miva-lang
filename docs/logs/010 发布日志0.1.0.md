# 🦉 Miva v0.1.0 Released
> **Parallel Platypus**

我们很高兴地宣布 **Miva 编程语言 v0.1.0** 正式发布！

本版本标志着 Miva 成长为完善的语言的关键一步，带来了**多版本共存**的核心能力，同时大幅优化了报错体验。Miva 正在成为一门兼具表达力与系统级能力的现代编程语言，第一个大版本已经就绪。

---

## 🚀 核心更新

### 1. 点语法
引入.语法糖，模拟面向对象的逻辑

**语法：**
```miva
double = (x: int): int => x * 2

x := 2.double();
// 等价于
x := double(2);
```

**特性：**
- 在编译期展开，无运行时开销
- 查找范围为所有导入的模块和当前模块
- 可以链式调用，例如`2.double.double()`等价于`double(double(2))`

---

### 2. 多版本共存
这个版本里，Miva引入了版本共存机制。项目可以指定依赖的版本，系统也能安装同一个库的不同版本

**语法：**
```toml
[dependencies]
std = "0.1.0"
foo = "0.0.2"
```

**特性：**
- 无`dependencies`字段的旧代码不受影响
- 含`dependencies`的新代码，会检查项目依赖是否明确包含，否则报错

---

### 3. Miva工具链上新
支持OCaml里的dep命令，和随版本系统一起到来的get命令——用Rust实现！

**使用：**
```bash
miva dep # 列出项目依赖，从入口文件开始
miva get https://github.com/username/reponame 0.0.1 # 从Github下载Miva库
miva get ./foo 0.0.1 # 从本地安装Miva库
```

**重点：**
- 安装时需要指定Tag或Branch，若指定Tag，不需要加v
- 目前，切换版本会丢失所有安装的第三方库，这个问题会在v0.1.1修复

---

### 4. Inline关键字
Miva长期以来有一个痛点：c关键字。
这让a、b之后不能用c做变量。
如今，c关键字替代方案来了：inline

**使用：**
```miva
inline unsafe foo = () => {} // 完全一样，不过c变成了inline
```

**注意：**
- c目前仍然是关键字，预计v0.2.0会去除
- 对于使用c unsafe的旧代码，会抛出弃用警告，请尽快迁移

---

### 5. 报错美化
对编译期的报错进行了美化。现在，报错不仅展示行列，还展示Rust风格的上下文：帮助您更快、更好地定位和解决问题
