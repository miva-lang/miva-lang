# Miva v0.1.1 Released
> **Dual Lynx**

我们很高兴地宣布 **Miva 编程语言 v0.1.1** 正式发布！

本版本标志着 Miva 成长为完善的语言的关键一步，带来了全新的LLVM与MVM后端。

---

## 🚀 核心更新

### 1. LLVM与MVM后端
此前的Miva一直是编译到C++的。
0.1.1带来了两种新的方式：LLVM和MVM。
LLVM是Clang发明的IR形式，比C++更接近底层。
MVM则是Miva自研的虚拟机，启动飞快、跨平台好，同时一个项目打包为一个.mvm文件，避免Java式的.class地狱

**使用方法：**
```bash
miva build -b llvm # LLVM后端
miva build -b mvm # MVM后端
miva build -b cpp # C++后端

miva run -b llvm # LLVM后端
miva run -b mvm # MVM后端，也可以用miva run --mvm
miva run -b cpp # C++后端
```

**带泛型编译速度对比**：

| 类型      | C++  | LLVM | MVM   |
| ------- | ---- | ---- | ----- |
| Debug   | 6.2s | 2s   | 0.04s |
| Release | 4.9s | 1.7s | 0.04s |

**总结**：
- 日常开发，用MVM形式，最快，瞬间出结果
- 发布版本，用LLVM形式，性能最好，不依赖虚拟机

---

### 2. 构建脚本支持
这个版本里，Miva引入了构建脚本支持，类似Node.js

**语法：**
```toml
[scripts]
dev = "miva run --mvm"
```

```bash
miva dev # 运行
```

---

### 3. Sin系列正式弃用
`sin-build`和`sin-run`正式弃用，从今请用`build`和`run`

**重点：**
- 运行`sin-build`和`sin-run`会报错，然后无事发生

---

### 4. Reinit命令
`reinit`命令用于重置`miva.toml`，参数同`init`命令
```bash
miva reinit <project> -t <type>
```

---

## 📦 破坏性更新

**本版本无破坏性语法更新**，所有功能均为新增扩展，**v0.1.0 代码可直接兼容运行**。
对于**使用单文件构建的项目**，需要迁移。
