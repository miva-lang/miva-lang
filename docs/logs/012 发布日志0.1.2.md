# Miva v0.1.2 Released
> **Resilient Octopus**

我们很高兴地宣布 **Miva 编程语言 v0.1.2** 正式发布！

本版本标志着 Miva 成长为完善的语言的关键一步，带来了std标准库的全新升级和异步操作。

---

## 🚀 核心更新

### 1. std添加五个新模块
在0.1.2中，std添加了std/json、std/toml、std/yaml、std/xml、std/vec五个

**std/json示例：**
```bash
std.json.parse(ref s)             // 解析字符串 -> ptrany（JSON 树）
std.json.object_get(ref v, i)     // 按索引获取对象/数组元素
std.json.object_len(ref v)        // 键/元素数量
std.json.object_key(ref v, i)     // 按索引获取对象键
std.json.object_find(ref v, k)    // 按键查找对象值
```

**注意**：
- 文档已经涵盖了std/下的使用，此处不再赘述
- 对于旧版本，需要使用miva reinit来指定std为0.1.2，方可使用全新标准库

---

### 2. 异步函数支持
这个版本里，Miva引入了规划已久的异步函数async/await支持。

**语法：**
```miva
async square = (x: int): future[int] => { // 必须返回future[T]
  return x * x;
}
f := square(5);                       // f 立即是 future[int]，任务已在后台运行
a := square(3).await();               // 阻塞直到 square(3) 结束
```

## 📦 破坏性更新

**本版本无破坏性语法更新**，所有功能均为新增扩展，**v0.1.1 代码可直接兼容运行**。
对于**使用单文件构建的项目**，需要迁移。
