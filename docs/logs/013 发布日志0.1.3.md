# Miva v0.1.3 Released
> **Nimble Tiger**

我们很高兴地宣布 **Miva 编程语言 v0.1.3** 正式发布！

本版本标志着 Miva 成长为函数式的关键一步，带来了ADT数据和高阶函数的支持。

---

## 🚀 核心更新

### 1. enum与ADT正式引入
在0.1.3中，添加了全新的enum类型；类似Rust，enum也是带类型的，同时支持泛型

**语法如下：**
```bash
Shape = enum {
  Circle(int),
  Rect(int, int),
  Empty
}
Option[T] = enum {
  Some(T),
  None
}
```

---

### 2. choose新功能
这个版本里，choose添加了守卫和模式解构的功能。

**语法：**
```miva
area = (s: Shape): int => choose (s) {
  when (Shape.Circle(r)) { return r * r; }
  when (Shape.Rect(w, h)) { return w + h; }
  otherwise { return 0; }
} // 模式解构
describe = (opt: Option[int]): int => choose (opt) {
  when (Option.Some(n)) if (n > 0)  { return n; }
  when (Option.Some(n)) if (n == 0) { return 0; }
  when (Option.Some(n))            { return n * -1; }
  otherwise { return -1; }
} // 守卫
```

---

### 3. std的Option与Result
这个版本里，std新增了option与Result库，两者均模仿Rust。

**Result示例：**
```miva
std.result.ok[T, E](v)                  // 将值包装进 Ok
std.result.err[T, E](e)                 // 将错误包装进 Err
```

具体用法已经在文档中说明。

## 📦 破坏性更新

**本版本无破坏性语法更新**，所有功能均为新增扩展，**v0.1.2 代码可直接兼容运行**。
对于**使用单文件构建的项目**，需要迁移。
